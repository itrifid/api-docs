## Integration basics

- Call the API from your backend, not directly from the browser, so your API key stays private.
- Use the streaming feed for live matches and REST for fixtures and completed scorecards.
- Cache data that does not change, such as fixtures and finished matches.
- Handle suspended markets and abandoned matches in your application logic.
